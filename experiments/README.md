# Experiments

What we set out to find with the lab, written down before each experiment ran.

- **`spec/`:** one file per experiment, each statement a question or hypothesis with a name. Each file ends with the configs and prompts that run it and the analysis that answers it.
- **`references.md`:** the papers we build on.

The findings are in `reports/<experiment>/`.
