# Reproducibility

- **response-cache:** Every model reply is stored under everything that shaped it (model, address, reasoning setting, messages, temperature, token limit, seed, attempt and the agent asking), so re-running a config and seed replays it exactly, reasoning included, without calling the model again; identical requests made at the same moment share one call.
- **cache-modes:** A run can use the cache, refresh it or leave it out; a fresh sample comes from a new seed, never from clearing the cache.
- **manifest:** Every run records what produced it: the resolved config, a hash of each prompt file it used, the code version, package versions, the model versions that answered, and its calls, tokens, cache hits and cost (the sum of what each call cost), saying how many calls had no known cost.
- **replay-pinned:** A fixed run with every condition on has its turn log, resolved config and cache keys pinned by hash, and every committed run's gains are recomputed from the prices it logged, so a change that alters what replays, what resumes or what the cache answers fails a test.
- **provenance-log:** Every `lab run`, `lab explore` and `lab debrief` that plays or asks anything appends one line to `runs/index.jsonl`, which is only ever appended to (and merges as a union, so branches that each append to it never conflict): when it started and ended, its command line, the lab's commit and whether the checkout had uncommitted changes, its spend cap, what it spent (a debrief records its estimate, since its calls aren't priced one by one), its output folder and the session that ran it (`LAB_SESSION`); every run made before the log existed gets a line from its manifest, marked `backfilled`.
- **reported-numbers-checked:** One command, `make reproduce`, recomputes offline from committed files every committed run's mean price and gain per firm (from its turn log, in its own market), the paper's tables and every quoted moment, and fails on any that no longer match what is committed.
- **cache-archive:** `lab archive pack` gathers, from every local response cache it is given, the replies behind each committed run into `archive/`, committed with the repository: compressed files of replies alone, one per experiment and split so none is over 20 MB, with an index from each run to its file, by replaying the run offline against them (a reply no cache holds is reported, never fetched), and says which runs the archive reproduces exactly, decision for decision and free-time reply for reply against their committed logs (an older log that kept no free-time reply is compared on its moves alone), and which it can't replay at all (a prompt file since removed); `lab archive replay` plays a run again from the archive alone, offline, so anyone holding the archive can rebuild a run's full turn log.
