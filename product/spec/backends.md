# Backends

- **any-model:** Any model is one string in the config, whatever serves it: a hosted provider, OpenRouter, a local server or any OpenAI-compatible address.
- **sampling-from-config:** Temperature, token limit and seed come from the config, and providers that can't take a seed still run.
- **keys-from-environment:** API keys come from the environment or the `.env` file in the folder the lab runs from, never from a config; a model at its own address (`api_base`) gets only the key in the variable its agent's `api_key_env` names, so no provider's key is ever sent to another address, and a key an error message echoes back is masked before it is logged.
- **self-hosted:** A model is self-hosted only when its agent says so (`self_hosted: true`, which needs its own address); a paid provider reached at its own address is priced, estimated and counted against the spend cap like any other. A self-hosted model: `lab run` says it is billed by its host's GPU time rather than estimating a per-token price for it, and its calls cost nothing against the spend cap; while its host is still starting up (answering 503), calls keep waiting for up to 20 minutes instead of giving up after the usual retries.
- **modal:** One command deploys an open model on Modal behind an OpenAI-compatible address where every route but its health checks needs a token kept in a Modal secret, and the token never appears in the server's logs, `configs/modal.yaml` runs the lab against it, and the README says how to set up, deploy, run and tear down.
- **model-aliases:** Short names stand for the lab's usual models (`gemma`, `gpt`, `haiku`, `mistral`, and `modal-mistral` for Mistral Small on your own Modal deployment, whose address comes from `MODAL_VLLM_BASE` in the environment or `.env`), so a config, a sweep or `lab explore` names a model in one word, from one table; an alias sets the model, its address, its key variable and whether it is self-hosted together, so swapping one alias for another never leaves the old address behind.
- **model-metadata:** Every model the lab has used (each alias, and every model in a committed run) has an entry in `models/metadata.yaml`: its provider, release date, whether its weights are open (with the parameter count when published) and a few published benchmark scores; every value carries the URL it was read from, the words it was read in and the date, and a figure no source publishes (or publishes only as an estimate, or only for another variant than the one our runs play) is left blank with a note, never estimated.
- **usage-logged:** Each turn logs the tokens every call used (a retried turn keeps both) and the model version the provider reports; how long it took, and any provider errors it got past, go in a separate timings log, so the turn log stays the same on replay.
- **transient-errors-retried:** Rate limits, timeouts (a call that hangs is cut off after a few minutes) and provider server errors are retried a few times with growing waits before a run gives up; errors that won't fix themselves, such as a bad key or an unknown model, stop it at once with one line naming the model.
- **shared-rate-limit:** When a provider says a model is rate-limited until a given time, every game calling that model waits until then, so parallel games don't use up their retries on it; a limit that won't lift within a couple of minutes stops the run and says when it lifts.
- **spend-asks-first:** Before a run calls any paid model, it says how many calls it will make and what they are estimated to cost from the provider's price list, and waits for a yes.
- **reported-cost:** Calls through OpenRouter ask for and record the cost OpenRouter reports for each call; other providers' calls keep LiteLLM's price, or none when it doesn't know one.
- **spend-cap:** A run can be given a spending cap: it refuses to start when its estimate is over the cap, stops cleanly once what it has actually spent passes it, and warns when a model has no price, since the cap can't count its calls.
- **reasoning-setting:** Each agent can set its model's reasoning to off, low, medium or high, sweepable like any other value; the setting reaches the provider in that provider's own form, and models without the option still run.
- **reasoning-in-estimate:** The estimate before a run counts every reply token a call is billed for, reasoning included: from what earlier calls of the same model, reasoning setting and phase actually billed, once the lab has seen enough of them, and otherwise from a stated upper figure per call; it says which basis it used, for how many calls.
- **quiet-provider-logs:** The model library's info and debug logging stays off unless asked for, so the errors that matter stand out.
- **tests-never-pay:** Tests never reach a real model; any call that isn't faked fails.
